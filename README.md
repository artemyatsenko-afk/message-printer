\# MessagePrinter — Java Project



\## Опис проєкту



MessagePrinter — консольна програма мовою Java, розроблена для вивчення основ роботи з Git та GitHub.



Програма виводить у консоль:

\- Привітальне повідомлення.

\- Інформацію про автора.

\- Поточний час.

\- Поточну дату.

\- Повідомлення про роботу з віддаленими репозиторіями.

\- Завершальне повідомлення.



\## Використані технології



\- Java

\- Git

\- GitHub

\- Windows Command Prompt (CMD)



\## Інструкція запуску



1\. Встановити Java JDK.

2\. Клонувати репозиторій:



&#x20;  `git clone https://github.com/artemyatsenko-afk/message-printer.git`



3\. Перейти до папки проєкту:



&#x20;  `cd message-printer`



4\. Скомпілювати програму:



&#x20;  `javac --release 8 MessagePrinter.java`



5\. Запустити програму:



&#x20;  `java MessagePrinter`



\## Робота з Git та GitHub



Під час виконання лабораторної роботи були використані:

\- Створення та клонування репозиторію.

\- Робота з гілками Git.

\- Створення комітів.

\- Завантаження змін через git push.

\- Створення та об'єднання Pull Request.

\- Розв'язання конфліктів на GitHub.

\- Розв'язання локальних конфліктів.

\- Синхронізація локального та віддаленого репозиторіїв.
